# UNK-Compartilhamento-de-tela
Aplicacao web UNK para compartilhar uma tela com outra pessoa, sem cadastro, extensao ou instalacao. A captura usa `getDisplayMedia()`, a midia trafega por WebRTC e o servidor cria salas temporarias e encaminha a sinalizacao por Socket.IO. A rota WebSocket original continua disponível para compatibilidade.
